# contacts/ — people & companies

One Markdown file per company or person worth remembering. Created when a
contact, lead, or relationship comes up that doesn't belong in a note or a task.

## Rules

- One file per company (preferred) or standalone person. Name files
  `kebab-case.md` from the company/person — e.g. `wise-coatings.md`.
- When a company has people, list them under a `## People` section with name,
  role, and how to reach them. Preserve exact name spellings the user gives
  (e.g. "Kourtney with a K").
- Keep a `## Notes` / `## History` area for context: how you met, what you want
  from the relationship, dated updates (`- YYYY-MM-DD — ...`).
- Action items that come out of a contact go to `../tasks/tasks.md`, not here —
  this folder is the who/what, the task list is the to-do.
- Never delete a contact unless explicitly asked; mark them inactive instead.
